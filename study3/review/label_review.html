Label rules. Label 1 (supports E11.22) only if: type 2 diabetes is documented (no stated type defaults to type 2); CKD is an established diagnosis; CKD is addressed at this visit (a copied plan line with "continue regimen" or "stable", or CKD in a reviewed list of conditions, counts; "see nephrology note" alone does not; a medication change made because of kidney function counts); the CKD is not attributed to a different cause instead of diabetes (diabetes plus another cause still counts); the visit is face-to-face with an MD, DO, NP or PA (R1); and the note is signed with credentials (R2). Secondary diabetes is not type 2 (R3). When sections conflict, the current assessment and plan governs; a documented stage counts even if the labs disagree; ESRD on dialysis supports E11.22; "CKD?" is not established. Some notes contain deliberate scanning noise (for example "C1inician", words split across lines, a stray page header); that is not an error.
