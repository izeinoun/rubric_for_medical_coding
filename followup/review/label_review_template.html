Label rules. Label 1 (supports E11.22) only if: type 2 diabetes is documented (no stated type defaults to type 2); CKD is an established diagnosis; CKD is addressed at this visit; no non-diabetic cause is given for the CKD; the visit is face-to-face with an MD, DO, NP or PA (R1); and the note is signed with credentials (R2). Secondary diabetes is not type 2 (R3). Some notes contain deliberate scanning noise (for example "C1inician", words split across lines, a stray page header); that is not an error.
